## 🏛️ Identidade Visual & Arquitetura

O site foi construído com uma direção de arte **minimalista e brutalista-editorial**, inspirada em estúdios de design contemporâneos e portfólios de pesquisa:

- **Modos Dia e Noite**: Alternador de tema integrado com persistência no `localStorage`, respeito à preferência do sistema operacional (`prefers-color-scheme`) e script anti-flash no carregamento.
- **Tipografia Editorial & Espaço Negativo**: Composição assimétrica com contrastes marcantes entre tipografia display (`Syne`), corpo de texto humanista (`Plus Jakarta Sans`) e metadados estruturados (`Space Mono`).
- **Cursor Dinâmico & Interações Sutis**: Micro-interações discretas, cursor magnético para desktop e transições suaves que respeitam `prefers-reduced-motion`.
- **Leitor de Markdown Integrado**: Interface minimalista em gaveta/modal que permite leitura contínua de ensaios e documentações de código sem sair do índice.
- **Suporte Nativo a Jekyll e GitHub Pages**: Estrutura 100% estática, sem necessidade de ferramentas de build pesadas ou dependências de servidor.
