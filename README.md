## ⚡ System Architecture & Features

This repository is styled as an immersive **Cyberpunk Cyberdeck** built with high-contrast neon aesthetics, HUD framing, audio feedback, and accessible responsive typography:

- **Mission Control Cyberdeck (`index.html`)**: Interactive dashboard with real-time HUD telemetry clock, dynamic card filtering, and an in-deck holographic markdown reader.
- **Synthesised Sci-Fi Web Audio**: Native browser Web Audio API generating futuristic tactile UI blips and chirps (toggleable with persistent mute state).
- **Toggleable CRT Scanlines**: Authentic retro-futuristic CRT scanline overlay with persistent user toggle.
- **Jekyll Cyberpunk Layouts (`_layouts/default.html`)**: Native GitHub Pages integration automatically wraps all markdown files in the cyber HUD theme when viewed directly.
- **Full Course Preservation**: All core course protocols, weekly maker dispatches, reflections, and AI audit logs are preserved and directly accessible.
